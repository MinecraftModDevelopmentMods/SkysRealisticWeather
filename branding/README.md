# Sky's Realistic Weather logo

Use [SkysRealisticWeatherLogo.png](SkysRealisticWeatherLogo.png) as the project
icon on CurseForge and other mod listings. It is a 1254 × 1254 PNG with a
transparent background and padding around the complete outline.

The four terrain patches represent the seasons; the cloud, sun, rain and snow
identify the weather theme. Keep the square canvas and transparent padding
when resizing the icon.
