# Changelog

## 0.1.22.110021

- Added translated item names, thermometer instructions, HUD labels and
  keybindings in the same language variants as the other Sky's mods.
- Included the correct Austrian German locale alongside the older alias.

The seasons, weather patterns, farming rules and heating behaviour are
unchanged. The config and admin editors still use English.

## 0.1.21.110021

- Added configurable warmth from fire, lava and ordinary torches, with warmth
  fading as you move away from each source.
- Kept overlapping heat sources from adding together unrealistically.
- Added modpack scripting, crop information and optional survival integrations.
