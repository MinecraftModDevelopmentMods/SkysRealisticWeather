# Changelog

## 0.1.21.111021

Sky's Realistic Weather is now available for Minecraft 1.11.2. This brings over
the changing seasons, local climates, farming support, thermometers and local
heating from the 1.10.2 version.

- Added support for the 1.11.2 versions of the optional farming, information,
  survival and terrain mods listed in the compatibility guide.
- Kept terrain providers' normal tree and park generation working during winter.
- Made the JEI climate panel fit smaller windows, with the full explanation
  available from its question-mark tooltip.
- Fixed item names and thermometer labels showing their untranslated keys.
- Added translated item names, thermometer instructions, HUD labels and
  keybindings in the same language variants as the other Sky's mods.

The default year is still 365 Minecraft days, with Per Biome Climate enabled.
RTG, Thaumcraft and AgriCraft support remains available on 1.10.2; they are not
included in the 1.11.2 compatibility list. The config and admin editors still
use English.
